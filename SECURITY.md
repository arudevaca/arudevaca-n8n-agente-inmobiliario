# Security notes

These workflow exports have been sanitized for public GitHub use.

Before importing them into n8n, replace the `YOUR_*` placeholders with your
own credentials/configuration inside n8n. Do not commit API keys, OAuth secrets,
access tokens, passwords, or production webhook secrets.

If a real access token was previously committed to a public repository, revoke
it at the provider and issue a new token before publishing the sanitized files.
